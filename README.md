# EduNest

EduNest is a production-grade SaaS platform where coaching institutes can register and list their institutes, and users can discover nearby coaching institutes based on location, ratings, category, fees, and timings.

## Tech Stack
- MongoDB Atlas
- Express.js
- React.js (Vite)
- Node.js
- Tailwind CSS
- Socket.io
- Framer Motion

## Structure
- `/client` - React frontend
- `/server` - Node.js backend

## Getting Started

1. Set up env variables based on `.env.example` in both client and server.
2. Run `npm install` in both directories.
3. Start server: `cd server && npm run dev`
4. Start client: `cd client && npm run dev`
